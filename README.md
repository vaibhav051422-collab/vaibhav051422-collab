## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/vaibhav051422-collab/vaibhav051422-collab.git
cd vaibhav051422-collab

# Install dependencies
npm install

# Start the development server
npm start
```

Then open [http://localhost:3000](http://localhost:3000) to view it in your browser.
